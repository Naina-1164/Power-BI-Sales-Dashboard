# Weekly Sales Dashboard V2 — guided Power BI exercise

**Status:** Instructions only; an editable `.pbix` file has not been created.

1. Import `weekly_sales.csv` as table `WeeklySales` in Power BI Desktop.
2. Create measure `Total Sales = SUM(WeeklySales[Sales])`.
3. Create measure `Average Sales = AVERAGE(WeeklySales[Sales])`.
4. Add cards for both measures and a clustered column chart (Day on X-axis, Sales on Y-axis).
5. Add a Day slicer. Selecting Saturday should show 2,500 in both cards.
6. Selecting Monday and Tuesday should show Total 2,700 and Average 1,350.
7. Save as `weekly_sales_dashboard_v2.pbix` when completed in Power BI Desktop.
