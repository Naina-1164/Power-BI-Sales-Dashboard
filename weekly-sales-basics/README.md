# Weekly Sales Report — Version 1

Beginner Power BI exercise using seven days of sample sales data.

## Dataset
Import `weekly_sales.csv` in Power BI Desktop using **Get data → Text/CSV**. Name the table `WeeklySales`; check that `Sales` is a whole number.

## Build the report
1. Add a Card for **Sum of Sales**: 11,900.
2. Add a Card for **Average of Sales**: 1,700.
3. Add a clustered column chart: **Day** on X-axis, **Sum of Sales** on Y-axis.
4. Add the heading **Weekly Sales Performance — Version 1**.
5. Save as `weekly_sales_report_v1.pbix` and add the PBIX file here once created in Power BI Desktop.

## Check
Highest sales: **Saturday — 2,500**.
